# Follow PSR-12 instead of Drupal's coding standard

Date: 2026-11-15

_Drafted with the `adr-suggestions` AI skill._

## Status

Proposed

## Context

Although this library is for Drupal sites, it's plain PHP that doesn't use Drupal's APIs, and it's loaded from `settings.php` before Drupal bootstraps, so it follows the general PHP coding standard. Adopted in `2aa04e0` (#29, 2026-09-03).

_The reason above was suggested by the `adr-suggestions` AI skill, without a written source, and chosen by the maintainer. Someone who was part of the decision should check it, then remove this line._

## Decision

We will follow PSR-12, checked by phpcs (`phpcs.xml.dist:6`), with additional sniffs where an ADR requires them, such as `Generic.PHP.RequireStrictTypes`.
