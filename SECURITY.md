# Security policy

## Supported versions

Security fixes go into the latest release of each supported branch:

| Branch | Versions | Supported |
| --- | --- | --- |
| `main` | 2.x | Yes, once 2.0.0 is released |
| `1.x` | 1.x | Yes |

## Reporting a vulnerability

Please don't report vulnerabilities in public issues or pull requests. Report them privately through GitHub instead: on the repository's **Security** tab, choose **Report a vulnerability**, or go straight to https://github.com/davereid/drupal-environment/security/advisories/new.

You'll get a reply there. Once a fix is released, the advisory is published with credit to you, unless you'd rather not be named.
